ecareafrica Reporting - Dashboards and Features

School Admin Dashboard (AppLayout)

- Dashboard (/dashboard)
	- KPI cards: Total Students, Present Today, Absent, SMS Sent
	- Daily attendance trend (Recharts area chart)
	- Class-by-class breakdown
	- Recent activity feed
	- Quick actions

- Attendance (/attendance)
	- Three scan modes: Card/QR, Face Recognition, Fingerprint
	- Face mode viewfinder UI with animated scanning line + randomized recognition
	- Fingerprint pulsing UI with success/error states
	- Card mode NFC/QR scan simulation
	- Success popup with student photo, class, time, parent SMS preview
	- Live attendance log table with status badges
	- Manual attendance override

- Student Management (/students)
	- Searchable and filterable student directory
	- Register New Student modal
		1 Student Info
		2 Parent Info
		3 Review
	- Student profile drawer with attendance history, SMS log, biometric enrollment
	- Biometric Enrollment modal for face and fingerprint
	- Bulk actions, CSV export (simulated), per-row edit/delete
	- Download Excel template for student import
	- Import students from Excel/CSV

- Classes (/classes)
	- Class card grid (S1A-S6B) with level color coding
	- Detail drawer with student roster and attendance trend chart
	- Per-class stats and teacher assignment

- Staff (/staff)
	- Staff directory with grid and table views
	- 4-step registration modal: Personal, Role, Contract, Documents
	- Departments view and staff attendance log
	- Staff profile with role badges

- Fees (/fees)
	- Collection dashboard with Recharts
	- Student fees table with payment recording
	- Receipt generation modal (print + simulated PDF download)
	- Transactions ledger
	- Fee structure editor
	- Payment reminders (SMS triggered)

- Boarding (/boarding)
	- KPIs: occupancy, total beds, present/absent boarders
	- Dormitory grid with capacity bars
	- House detail slide-over
	- Roll call modal (Morning/Evening) with bulk mark
	- Absence monitoring panel

- Gate (/gate)
	- KPIs: on-campus count, today's entries/exits
	- Live campus status (auto-refreshing)
	- Tabs: Entry Analytics, Exit Analytics, Time-of-day Analytics
	- Duplicate entry prevention log

- Leaves (/leaves)
	- KPIs across leave statuses
	- Tabs: Pending, Approved, Rejected, All
	- Approve/Reject modals with SMS preview to parents
	- Exit tracking
	- 3-step New Leave modal: Reason, Dates, Parent confirmation

- Parents (/parents)
	- Searchable parent directory mapped to students
	- SMS Compose modal with EN/KIN templates and variable injection
	- Bulk SMS tool with simulated progress counter
	- SMS history per parent

- Notifications (/notifications)
	- Filterable SMS log (status, trigger, date)
	- Retry Failed action
	- Delivery status badges
	- Trigger-type icons (check-in, leave, fee reminder, etc.)

- Reports (/reports)
	- Tabs: Overview, By Class, By Student, By Time
	- Recharts area and bar charts
	- Sortable tables
	- Attendance heatmap (week x period)
	- Daily trend and weekly comparison

- Settings (/settings)
	- Tabs: School Info, SMS API Configuration, Academic Calendar (holidays), Biometric thresholds,
		Roles and Permissions (edit modal), Subscription and Plan (usage meters + upgrade modal)

- Visitors (/visitors)
	- Register visitor (check-in)
	- Stat cards: Today's visitors, On Campus, Pending Check-out, This Week Total
	- Tabs: Active Visitors, Scheduled, History, Logs
	- Active Visitors table with view and check-out actions
	- Scheduled visits with confirm check-in and cancel actions
	- History search and date filter with visit duration
	- Logs of entry/exit events with gate officer

Staff Dashboard (StaffLayout)

- Staff Dashboard (/staff/dashboard)
	- Stat cards: On campus, Pending leaves, Visitors, Absent boarders
	- Live campus status (entry/exit counts)
	- Emergency lockdown action
	- Daily tasks checklist
	- Recent activity feed

- Gate Control (/staff/gate)
	- Entry/Exit scan interface with manual ID input
	- Today's gate log table
	- Pending exits table with overdue tracking
	- Alerts tab
	- Lockdown and print actions

- Visitors (/staff/visitors)
	- Redirect to unified visitor management module

- Boarding Roll Call (/staff/boarding)
	- Roll call form with dorm/session selection
	- Student attendance table with status buttons
	- Dorm summary stats: present/absent/leave counts
	- Mark all present action

- Leave Requests (/staff/leaves)
	- Tabs: pending/approved/rejected/exit tracking
	- Stat cards for leave counts
	- Leave requests table
	- Detail modal with approval/rejection actions

- Absence Alerts (/staff/alerts)
	- Active alerts by severity (high/medium/low)
	- Alerts history table
	- Alert rules section

- Student Lookup (/staff/students)
	- Search and class filter
	- Student cards with parent phone
	- Detail drawer with gate log and SMS action

- My Attendance (/staff/my-attendance)
	- Monthly attendance progress chart
	- Leave balance breakdown
	- Stats: on-time percent, hours/day, streaks
	- Attendance history table

- My Profile (/staff/profile)
	- Avatar and personal info card
	- Tabs: personal/work/security
	- Editable personal form
	- Work info display
	- Password change form

Teacher Dashboard (TeacherLayout)

- Teacher Dashboard (/teacher/dashboard)
	- Stat cards: classes, students taught, present percent, pending tasks
	- Today's schedule list with take-attendance links
	- Quick actions: attendance, exams, messages, schedule
	- My classes cards with attendance percent and class teacher badge

- My Classes (/teacher/classes)
	- Class card grid with student count and attendance bar
	- Class drawer with students/attendance/exams tabs

- Attendance (/teacher/attendance)
	- Class/period/date selectors
	- Searchable student list
	- Status buttons: Present, Absent, Late, Excused
	- Attendance counts and submission confirmation
	- History tab

- Exams and Results (/teacher/exams)
	- Tabs: upcoming, enter results, published
	- Upcoming exams table
	- Create exam modal
	- Published results cards with pass rate and average score
	- Detailed results modal with chart

- Student Progress (/teacher/progress)
	- Class selector
	- Student ranking table with attendance, marks, trend, status
	- At-risk alert banner
	- Student drawer with marks trend chart and stats

- Parent Messages (/teacher/messages)
	- Message list with filters (all/unread/sent) and search
	- Thread view with message history
	- SMS template insert, send via SMS toggle, character counter
	- Compose modal

- Notifications (/teacher/notifications)
	- Filter tabs: all/attendance/academic/system/message
	- Type-based icons and colors
	- Mark all as read action
	- Type-specific actions

- My Profile (/teacher/profile)
	- Avatar and basic info card
	- Tabs: personal/work/security
	- Personal form
	- Work info with assigned classes list
	- Password form with last login info

- My Schedule (/teacher/schedule)
	- Timetable grid and list views
	- Week navigation
	- Period schedule with class/subject assignments
	- Print action

Super Admin Dashboard (SuperAdminLayout)

- Platform Overview (/super-admin)
	- KPIs: total schools, active subscriptions, MRR, system health
	- Platform charts and recent activity feed

- Schools (/super-admin/schools)
	- Tenant school grid
	- 5-step school onboarding modal: Identity, Contacts, Plan, Modules, Confirmation

- Subscriptions (/super-admin/subscriptions)
	- Plans table and active subscriptions

- Billing (/super-admin/billing)
	- Platform-wide invoices and revenue

- Analytics (/super-admin/analytics)
	- Cross-tenant usage analytics

- System (/super-admin/system)
	- Default SMS provider selection
	- Global notification templates
	- Feature flags (Boarding, Biometrics, Gate, Bulk SMS, CSV export)
	- Maintenance mode toggle

- Platform Users (/super-admin/users)
	- Internal ecareafrica team accounts

- Announcements (/super-admin/announcements)
	- Broadcast announcements to tenant schools
